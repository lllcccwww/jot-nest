# Jot — 桌面便签画布应用（MVP）

## 目标

把"随手复制了文本/图片 → 丢进微信或记事本 → 事后找不到"的碎片，收敛成一个**空间化**的桌面工具：全局热键两秒记下，卡片落在无限画布上，靠位置、颜色、标签找回；数据本地为真相源，腾讯 COS 做异地备份与自动更新源。

单机自用，Windows 首发。

## 需求（已与用户确认）

### 捕捉
- 全局热键（默认 `Ctrl+Alt+N`，可配置、带录制与冲突检测）唤出浮窗：约 560px 宽，屏幕水平居中、垂直偏上，无边框，失焦自动隐藏，`Esc` 关闭。
- 浮窗内 `Ctrl+V` 直接粘贴：文字显示文字，图片显示缩略图预览；文字 + 一张图可合成一张卡。
- 提交入口：`Ctrl+Enter` 或点"保存"按钮（`Enter` 仅换行）。提交后关闭浮窗并提示"已保存 · 定位"。
- 主窗口内也可直接新建卡片。

### 画布
- **单张无限自由画布**，滚轮平移、`Ctrl+滚轮`/按钮缩放、空白处左键框选、中键或空格拖拽平移。
- 新卡片落位于当前视口中心附近（带放射偏移避免完全重叠）；提供"飞回最近一条"按钮。
- 卡片三档宽度（240 / 320 / 480）+ 高度自适应，超过约 12 行折叠；双击就地编辑。
- 框选多选、拖动时智能吸附参考线（边缘/中心对齐）、分组容器（可命名、整体移动、折叠）、卡片上色。
- **不做连线**。

### 内容与元数据
- 类型：纯文本（轻量 Markdown 预览）+ 图片。
- 元数据：标签（多标签）、收藏（pinned）、底色、创建/更新时间。
- 不设"收件箱"状态；新卡片 24 小时内带弱"新"标记，自动消失。

### 找回
- 顶栏常驻搜索框（文字 / 标签 / 时间范围 / 仅收藏 chip）。
- 命中卡片在画布上高亮、其余淡出；点击或 `Enter` 相机飞行定位并居中。
- "全览"按钮缩放到适配全部卡片。

### 视觉
- 中性纸面基调，可选低饱和卡片底色（6 色），亮/暗双主题。
- 无边框自绘标题栏（拖动区、双击最大化、自绘窗口控件）。
- 动效 120–200ms，不做弹跳。

### 窗口与常驻
- 关闭 = 收进托盘；托盘单击恢复主窗口，右键菜单含捕捉/打开/同步状态/退出。
- 可选开机自启；单实例运行。

### 存储与备份
- 本地 `%APPDATA%\jot-nest\`：`jot.db`（SQLite）+ `images/`（原图，按 sha256 命名）+ `thumbs/`。
- COS：私有读写桶，上传 `jot.db` 快照与按 sha256 增量图片；密钥用 `safeStorage` 加密存储。
- 同步状态：已同步 / 同步中 / 失败可重试；设置页可"立即备份"。
- 单机，无冲突解决；字段保留 `updated_at / rev` 以便未来多端。
- 不做导出功能。

### 图片
- 原图保存；长边 > 4096 或体积 > 8MB 时降采样一次（渲染进程 canvas 完成，无原生依赖）。
- 另存 512px 缩略图供画布使用，点开看原图。

### 交互基调
- **鼠标优先**：所有功能有可见入口按钮，快捷键仅作加速器。唯一必需快捷键是全局捕捉热键。

### 交付
- `electron-vite` 开发与构建；`electron-builder` 打 NSIS 安装包 + 便携版；`electron-updater` 自动更新（COS 上 `updates/` 前缀公开读）。

## 验收标准

1. `npm run dev` 启动后：主窗口无边框、标题栏可拖动、关闭进托盘、托盘可恢复。
2. 全局热键唤出浮窗 → 粘贴文字 → `Ctrl+Enter` → 主窗口画布上出现新卡片，位置在视口中心附近。
3. 粘贴图片 → 浮窗内可见缩略图 → 保存后画布显示缩略图卡片，点击可看原图。
4. 拖动画布卡片出现吸附参考线；框选多张后可成组，组可整体拖动、折叠。
5. 顶栏搜索输入中文子串（如"会议"）能命中卡片，其余卡片淡出，点击命中卡后相机居中。
6. 重启应用后卡片位置、标签、颜色、相机位置全部保持。
7. 在设置页填入 COS 配置并保存后，点击"立即备份"成功上传快照与图片；断网时状态显示失败且本地功能不受影响。
8. `npm run dist` 产出可安装的 exe。
